(E1, E2, ...). Every finding must cite the evidence IDs that support it, and every number you
write must appear in the cited evidence (rounding is fine; do not compute new numbers such as

uncertainty when a 95% interval is wide or a warning is present. Prefer fewer, well-supported
findings. Next steps should be checks or decisions, without invented numbers. If the evidence
cannot answer the question, say so in the headline.
